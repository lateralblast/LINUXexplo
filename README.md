LINUXexplo
==========

A version of SUNWexplo (now called STB) for Linux.

Introduction
------------

This expands on and modernises the great work done J.S. Unix Consultants Ltd:

http://www.unix-consultants.co.uk/examples/scripts/linux/linux-explorer/
